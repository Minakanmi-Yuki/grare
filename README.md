# GraRe project website

The public research project page for **GraRe: Grasp Candidate Re-Ranking for Frozen 6-DoF Grasp Detectors**.

- Website: https://minakanmi-yuki.github.io/grare/
- Paper and supplementary material: https://arxiv.org/abs/2608.00946
- Research code: https://github.com/Minakanmi-Yuki/grare

This `gh-pages` branch contains only the published static website. GitHub Pages serves its root directory directly; `.nojekyll` disables Jekyll processing. No build or dependency installation is required.

Edit `index.html`, `styles.css`, `app.js`, and the referenced files in `assets/` to update the page. Relative asset paths support deployment under `/grare/`.
