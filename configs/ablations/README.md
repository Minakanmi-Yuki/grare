# Ablation Release Policy

The public repository exposes the validated main-result configurations under
[`../`](../). The paper ablations are implemented by the same GraRe modules
and are reported in [../../docs/RESULTS.md](../../docs/RESULTS.md), but this
directory deliberately does not carry the broader exploratory sweep catalogue.

This boundary keeps the release focused on reproducible paper claims rather
than on intermediate hyperparameter searches.
